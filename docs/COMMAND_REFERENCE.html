1. Execution Modes

All scanning, auditing, and synchronization workflows operate under three standard verification depths. When omitted, the execution mode defaults to NORMAL.

Mode Inspection Scope Selection & Filtration Criteria
FAST Diff headers & metadata Evaluates subject keywords and touched files. Selects high-confidence P0 crash and critical P1 fixes. Skips speculative features.
NORMAL (Default) Full watermark range diffs & AST Standard triage. Audits all commits since watermark. Selects P0 stability fixes, P1 AI/combat/healing parity, and mature P2 enhancements.
DEEP Extended history, callers, blame Deep semantic comparison across CMaNGOS and vMaNGOS. Traces caller chains, dependency trees, and checks for semantic equivalence.

2. Command Specifications

status Read-Only

Displays total project health, target git branch, worktree cleanliness, upstream watermark locations, unscanned commit counts, and durable ledger statistics.

.\task.ps1 status
scan [cmangos | vmangos | all] [fast | normal | deep] Read-Only

Audits newly unscanned upstream commits from the specified donor without modifying any target files. Automatically classifies candidate commits (P0-P3, CRITICAL, RECOMMENDED, EXPANSION_INCOMPATIBLE) and updates the durable ledger.

.\task.ps1 scan all normal
.\task.ps1 scan cmangos deep
.\task.ps1 scan vmangos fast
sync [cmangos | vmangos | all] [fast | normal | deep] Full Pipeline

Executes the complete end-to-end synchronization pipeline: updates donor refs, audits candidate deltas, adapts eligible fixes natively, compiles modules.lib, links mangosd.exe, updates the ledger, commits to target, and pushes passing commits to mantech-turtle.

.\task.ps1 sync all normal
import-critical [cmangos | vmangos | all] Targeted Port

Discovers, ports, and verifies only high-severity P0 fixes: server crashes, null pointer exceptions, memory corruption, and fatal bot lifecycle failures.

.\task.ps1 import-critical all
audit <source> <commit-sha> Read-Only

Performs an isolated, deep semantic audit of one specific upstream commit. Evaluates target bug presence, Dungeon Clear impact, expansion compatibility, and adaptation steps.

.\task.ps1 audit cmangos 6ad783c9
.\task.ps1 audit vmangos ac4c83ad
port <source> <commit-sha> Targeted Port

Directly ports an explicitly requested commit and required dependencies using target-native APIs, runs verification, and updates the ledger.

.\task.ps1 port cmangos 46cec841
verify-quick & verify-full Verification Gate

Runs the target verification ladder:

  • verify-quick: Rapid compilation of affected static module code (modules.lib).
  • verify-full: Complete target server build and link of mangosd.exe.
.\task.ps1 verify-quick
.\task.ps1 verify-full
ledger [cmangos | vmangos] Reporting

Displays tabular status of all audited, ported, verified, duplicate, already-present, and rejected commits from state/porting-ledger.json.

.\task.ps1 ledger
.\task.ps1 ledger vmangos
roadmap Reporting

Displays active project milestones, phase progress (Phases 0-6), and prioritized backlog.

.\task.ps1 roadmap

3. Priority Tiers

Tier Classification Candidate Types
P0 CRITICAL Crashes, null pointer dereferences, assertions, memory leaks, bot provisioning deadlocks.
P1 RECOMMENDED Healer targeting priority, combat stances, threat calculations, pathing stalls, resurrect bugs.
P2 OPTIONAL / PENDING Quality-of-life improvements, travel distribution, inventory/food adjustments.
P3 DISQUALIFIED TBC/WotLK expansion mechanics, cosmetic noise, duplicate/already present code.
Verification Invariant: A source file compiling is never sufficient proof of success. mangosd.exe must link cleanly without unresolved externals before any commit is marked as verified or pushed to mantech-turtle.
Scope Boundary Invariant & Double-Confirmation Gate: Widening the scan scope into historical donor backlogs beyond the active watermarks is strictly PROHIBITED. If historical scope expansion is ever requested, the framework will not execute it immediately; it requires an explicit warning and a mandatory double-confirmation from the operator.
